# История изменений ML System Design Doc

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Версии документа: `MAJOR.MINOR`.
- **MAJOR** — документ согласован заново (встреча со стейкхолдерами, гейт).
- **MINOR** — правки без повторного согласования: уточнения, оформление, ссылки.

Каждая версия закрепляется git-тегом `doc-vX.Y`. Начиная с v2.1 каждая правка — отдельный коммит.

> Версии до v2.0 восстановлены ретроспективно: документ вёлся вне репозитория и был загружен одним коммитом. Даты и состав изменений восстановлены по рабочим заметкам и переписке команды.
